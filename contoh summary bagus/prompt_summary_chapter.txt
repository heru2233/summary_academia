## CONTOH PENULISAN

INTERPRETASI:
"Expected Return adalah rata-rata return yang diharapkan akan diterima investor dari suatu investasi di masa depan. Ini bukan return yang DIPASTIKAN akan diterima, melainkan return rata-rata tertimbang dari semua kemungkinan hasil yang bisa terjadi."

MENGAPA PENTING:
"Investor menggunakan expected return sebagai dasar untuk membandingkan investasi. Jika saham A punya E(R) = 15% dan saham B punya E(R) = 10%, maka secara rata-rata, saham A lebih menarik. Namun, ini belum mempertimbangkan RISIKO."

ANALOGI:
"Bayangkan Anda memiliki 2 keranjang buah:
- Keranjang A: 60% apel (rasa manis 15)
- Keranjang B: 40% jeruk (rasa manis 12)
Rasa manis rata-rata = (0.60 × 15) + (0.40 × 12) = 13.8
Anda tidak akan dapat rasa lebih manis dari apel (15) atau lebih asam dari jeruk (12)."

INSIGHT:
"Expected Return portfolio SELALU berada DI ANTARA return terendah dan return tertinggi dari aset-aset dalam portofolio. Anda TIDAK BISA mendapat return lebih tinggi dari aset terbaik atau lebih rendah dari aset terburuk hanya dengan diversifikasi."
