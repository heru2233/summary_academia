1. Expected Return (Rata-rata Tertimbang)

🎯 Apa itu Expected Return?

Expected Return adalah rata-rata return yang diharapkan akan diterima investor dari suatu investasi di masa depan. Ini bukan return yang DIPASTIKAN akan diterima, melainkan return rata-rata tertimbang dari semua kemungkinan hasil (outcome) yang bisa terjadi.

Mengapa penting? Investor menggunakan expected return sebagai dasar untuk membandingkan investasi. Jika saham A punya E(R) = 15% dan saham B punya E(R) = 10%, maka secara rata-rata, saham A lebih menarik. Namun, ini belum mempertimbangkan RISIKO.

Rumus 1: Expected Return per Saham
E(Rᵢ) = Σ Pₛ × Rᵢₛ

Keterangan:

  • E(Rᵢ) = Expected return saham i
  • Pₛ = Probabilitas kejadian s (total semua probabilitas = 1 atau 100%)
  • Rᵢₛ = Return saham i pada kejadian s

📝 Contoh Penerapan:

Misalkan Anda memiliki 3 skenario ekonomi untuk saham XYZ:

Skenario Ekonomi Probabilitas (Pₛ) Return (Rₛ)
Ekonomi Booming 25% (0.25) +20%
Ekonomi Normal 50% (0.50) +10%
Ekonomi Recession 25% (0.25) -5%

Perhitungan:

E(R) = (0.25 × 20%) + (0.50 × 10%) + (0.25 × -5%)

E(R) = 5% + 5% + (-1.25%) = 8.75%

Interpretasi: Jika Anda berinvestasi di saham XYZ, secara rata-rata Anda diharapkan mendapat return 8.75%. Namun, actual return bisa lebih tinggi (20%) atau lebih rendah (-5%) tergantung kondisi ekonomi.

Rumus 2: Expected Return Portfolio (2 Aset)
E(Rp) = w₁ × E(R₁) + w₂ × E(R₂)
Rumus 3: Expected Return Portfolio (N Aset)
E(Rp) = Σ wᵢ × E(Rᵢ)

Keterangan:

  • wᵢ = Bobot saham i dalam portfolio (proporsi dana yang diinvestasikan)
  • E(Rᵢ) = Expected return saham i
  • Σ wᵢ = 1 (total bobot harus 100%, artinya seluruh dana teralokasi)

🎯 Interpretasi Expected Return Portfolio

Expected Return Portfolio adalah rata-rata tertimbang dari return masing-masing aset dalam portofolio. Bobot (w) menunjukkan proporsi dana yang dialokasikan ke setiap aset.

Misalnya: Jika Anda menginvestasikan 60% dana ke ASII (E(R)=15%) dan 40% ke BBCA (E(R)=12%), maka:

E(Rp) = (0.60 × 15%) + (0.40 × 12%) = 9% + 4.8% = 13.8%

Insight Penting: Expected Return portfolio SELALU berada DI ANTARA return terendah dan return tertinggi dari aset-aset dalam portofolio. Anda TIDAK BISA mendapat return lebih tinggi dari aset terbaik atau lebih rendah dari aset terburuk hanya dengan diversifikasi.

🧊 Analogi Sederhana

Bayangkan Anda punya 2 keranjang buah:

  • Keranjang A: 60% apel (rasa manis 15)
  • Keranjang B: 40% jeruk (rasa manis 12)

Rasa manis rata-rata campuran buah = (0.60 × 15) + (0.40 × 12) = 13.8

Anda tidak akan dapat rasa lebih manis dari apel (15) atau lebih asam dari jeruk (12). Campuran selalu di tengah-tengah.

2. Measures of Dispersion (Ukuran Penyebaran)

🎯 Apa itu Variance dan Standard Deviation?

Variance (σ²) dan Standard Deviation (σ) adalah ukuran seberapa jauh return aktual bisa menyimpang dari expected return. Ini adalah ukuran RISIKO dalam teori portofolio.

Mengapa penting? Dua investasi bisa punya expected return yang sama, tapi risiko yang sangat berbeda. Misalnya:

  • Saham A: E(R) = 10%, σ = 5% → return relatif stabil
  • Saham B: E(R) = 10%, σ = 30% → return sangat fluktuatif

Investor yang risk-averse (menghindari risiko) akan memilih Saham A karena lebih stabil.

Rumus 4: Variance
σ² = Σ Pₛ × [Rₛ - E(R)]²

🎯 Interpretasi Variance

Variance mengukur rata-rata kuadrat selisih antara return aktual dan expected return.

  • Variance besar → return tersebar jauh dari rata-rata → RISIKO TINGGI
  • Variance kecil → return dekat dengan rata-rata → risiko rendah

Mengapa dikuadratkan? Karena selisih negatif dan positif keduanya merupakan risiko. Jika tidak dikuadratkan, selisih negatif dan positif akan saling meniadakan (total = 0). Dengan dikuadratkan, semua selisih menjadi positif.

Rumus 5: Standard Deviation
σ = √σ² = √(Σ Pₛ × [Rₛ - E(R)]²)

🎯 Interpretasi Standard Deviation

Standard Deviation adalah akar kuadrat dari variance, yang mengembalikan satuan ke satuan yang sama dengan return (persentase).

Interpretasi Praktis:

  • Jika E(R) = 10% dan σ = 5%, maka sekitar 68% kemungkinan return berada di antara 5% - 15% (E(R) ± 1σ)
  • Sekitar 95% kemungkinan return berada di antara 0% - 20% (E(R) ± 2σ)
  • Sekitar 99.7% kemungkinan return berada di antara -5% - 25% (E(R) ± 3σ)

Ini asumsi distribusi normal (bell curve).

📝 Contoh Perhitungan Variance & Std Dev

Menggunakan data saham XYZ dari contoh sebelumnya:

Skenario Pₛ Rₛ Rₛ - E(R) [Rₛ - E(R)]² Pₛ × [Rₛ - E(R)]²
Booming 0.25 20% 20% - 8.75% = 11.25% 0.01266 0.00316
Normal 0.50 10% 10% - 8.75% = 1.25% 0.00016 0.00008
Recession 0.25 -5% -5% - 8.75% = -13.75% 0.01891 0.00473
Total (Variance) 0.00797

σ² = 0.00797

σ = √0.00797 = 8.93%

Interpretasi: Return saham XYZ diharapkan 8.75% dengan risiko (volatilitas) 8.93%. Artinya, return bisa berfluktuasi sekitar ±8.93% dari nilai harapan.

🧊 Analogi Sederhana

Bayangkan Anda melempar anak panah ke target:

  • Sigma kecil = anak panah berkumpul rapat di dekat pusat target → AKURAT
  • Sigma besar = anak panah tersebar ke mana-mana → TIDAK AKURAT

Dalam investasi: sigma kecil = return KONSISTEN, sigma besar = return TIDAK PREDIKTABEL.

3. Covariance dan Correlation

🎯 Apa itu Covariance dan Correlation?

Covariance dan Correlation mengukur seberapa kuat hubungan antara return dua aset berbeda. Ini adalah KUNCI dari diversifikasi.

Mengapa penting? Jika dua aset bergerak berlawanan arah (korelasi negatif), ketika satu rugi, yang lain untung → risiko portfolio BERKURANG. Inilah dasar diversifikasi.

Rumus 6: Covariance
Cov(Rᵢ, Rⱼ) = Σ Pₛ × [Rᵢₛ - E(Rᵢ)] × [Rⱼₛ - E(Rⱼ)]

🎯 Interpretasi Covariance

Covariance mengukur arah dan kekuatan hubungan linear antara return dua aset:

  • Covariance POSITIF (+) → Kedua aset cenderung bergerak SEARAH (keduanya naik atau keduanya turun)
  • Covariance NEGATIF (-) → Kedua aset cenderung bergerak BERLAWANAN (satu naik, satu turun)
  • Covariance = 0 → Tidak ada hubungan linear antara kedua aset

Kelemahan Covariance: Nilainya dalam satuan "persen kuadrat" (misal: 0.0045), sehingga sulit diinterpretasikan secara langsung. Untuk itu, kita gunakan Correlation Coefficient.

Rumus 7: Correlation Coefficient
ρᵢⱼ = Cov(Rᵢ, Rⱼ) / (σᵢ × σⱼ)

🎯 Interpretasi Correlation Coefficient

Correlation Coefficient (ρ) adalah covariance yang sudah dinormalisasi sehingga nilainya selalu antara -1 sampai +1. Ini jauh lebih mudah diinterpretasikan.

Nilai ρ Interpretasi Efek Diversifikasi Contoh di Dunia Nyata
+1.0 Perfect positive correlation ❌ TIDAK ADA efek diversifikasi Saham dalam satu industri (BBCA & BMRI)
+0.5 Moderate positive correlation ⚠️ Efek diversifikasi sedang Saham teknologi & saham konsumer
0.0 No correlation ✅ Efek diversifikasi optimal Saham & Emas (kadang)
-0.5 Moderate negative correlation ✅ Efek diversifikasi tinggi Saham & Obligasi Pemerintah
-1.0 Perfect negative correlation ✅ ELIMINASI risiko sepenuhnya Sangat jarang ditemukan

💡 Insight Penting

Diversifikasi paling efektif ketika korelasi antar aset rendah atau negatif. Inilah mengapa:

  • Investor disarankan untuk diversifikasi ke berbagai sektor (korelasi antar sektor biasanya lebih rendah)
  • Investor disarankan untuk diversifikasi ke berbagai negara (korelasi antar negara biasanya lebih rendah)
  • Investor disarankan untuk mencampur saham dan obligasi (korelasi sering negatif)

📝 Contoh Korelasi dalam Portofolio

Misalkan Anda memiliki portofolio dengan 2 saham:

Saham E(R) σ
Bank (BBCA) 12% 18%
Mining (ADRO) 15% 25%

Skenario 1: Korelasi ρ = +0.8 (tinggi)

→ Saham cenderung bergerak searah → diversifikasi TIDAK efektif

Skenario 2: Korelasi ρ = +0.2 (rendah)

→ Saham tidak selalu bergerak searah → diversifikasi LEBIH efektif

Skenario 3: Korelasi ρ = -0.3 (negatif)

→ Saham cenderung berlawanan arah → diversifikasi PALING efektif

4. Portfolio Variance (2 Aset)

🎯 Mengapa Portfolio Variance Berbeda dari Variance Rata-rata?

Hal PALING PENTING dalam teori portofolio adalah: risiko portfolio BUKAN rata-rata dari risiko masing-masing aset. Risiko portfolio bisa LEBIH RENDAH dari rata-rata risiko aset-asetnya, tergantung korelasi antar aset.

Inilah mengapa diversifikasi bekerja:

  • Jika ρ < +1.0, maka σp < w₁σ₁ + w₂σ₂ (risiko portfolio lebih rendah dari rata-rata tertimbang)
  • Semakin rendah korelasi, semakin besar pengurangan risiko
Rumus 8: Portfolio Variance (2 Aset) - Bentuk Kovarian
σ²p = w₁²σ₁² + w₂²σ₂² + 2w₁w₂σ₁₂

🎯 Interpretasi Rumus Portfolio Variance

Rumus ini memiliki 3 komponen:

  1. w₁²σ₁² = Kontribusi risiko dari Saham 1 (variance saham 1 yang dikuadratkan bobotnya)
  2. w₂²σ₂² = Kontribusi risiko dari Saham 2 (variance saham 2 yang dikuadratkan bobotnya)
  3. 2w₁w₂σ₁₂ = Efek diversifikasi (kovarian antara kedua saham)

Insight Kunci:

  • Jika σ₁₂ negatif → komponen ketiga negatif → risiko portfolio BERKURANG
  • Jika σ₁₂ = 0 → komponen ketiga = 0 → risiko portfolio hanya dari variance individual
  • Jika σ₁₂ positif → komponen ketiga positif → risiko portfolio MENINGKAT
Rumus 9: Portfolio Variance dengan Korelasi
σ²p = w₁²σ₁² + w₂²σ₂² + 2w₁w₂ρ₁₂σ₁σ₂
Rumus 10: Portfolio Standard Deviation (2 Aset)
σp = √(w₁²σ₁² + w₂²σ₂² + 2w₁w₂ρ₁₂σ₁σ₂)

📝 Contoh Perhitungan Portfolio Variance

Anda memiliki portofolio 60% ASII dan 40% BBCA:

Saham σ² σ Bobot
ASII 0.04 20% 60%
BBCA 0.025 15.81% 40%
Korelasi (ρ) 0.30

Langkah 1: Hitung kovarian

σ₁₂ = ρ₁₂ × σ₁ × σ₂ = 0.30 × 0.20 × 0.1581 = 0.00949

Langkah 2: Hitung portfolio variance

σ²p = (0.60)²(0.04) + (0.40)²(0.025) + 2(0.60)(0.40)(0.00949)

σ²p = 0.0144 + 0.004 + 0.00456 = 0.02296

Langkah 3: Hitung portfolio std dev

σp = √0.02296 = 15.15%

Interpretasi:

  • Risiko rata-rata tertimbang = (0.60 × 20%) + (0.40 × 15.81%) = 18.32%
  • Risiko portfolio = 15.15%
  • Pengurangan risiko = 18.32% - 15.15% = 3.17%
  • Ini terjadi KARENA korelasi positif (0.3) yang rendah

💡 Kesimpulan Penting

Diversifikasi mengurangi risiko TANPA mengurangi expected return. Dalam contoh di atas, expected return tetap 13.8%, tapi risiko turun dari 18.32% ke 15.15%. Ini adalah "free lunch" dalam investasi!

5. Portfolio Variance (N Aset - Matrix Form)

🎯 Mengapa Perlu Bentuk Matriks?

Ketika portofolio memiliki lebih dari 2 aset, perhitungan menjadi kompleks. Rumus matriks memudahkan perhitungan dengan menggabungkan semua variance dan kovarian dalam satu operasi.

Rumus 11: General Portfolio Variance
σ²p = Σᵢ Σⱼ wᵢ wⱼ σᵢⱼ
Dalam Bentuk Matriks:
σ²p = w' × Σ × w

Dimana:
• w = [w₁, w₂, ..., wₙ]' (vektor bobot, transpose)
• Σ = matriks kovarian (N × N)
• w' = transpose dari vektor bobot

🎯 Interpretasi Matriks Kovarian

Diagonal matriks (σ₁₁, σ₂₂, ..., σₙₙ) = variance masing-masing saham

Di luar diagonal (σ₁₂, σ₁₃, ..., σₙ₋₁,ₙ) = kovarian antar pasangan saham

Sifat matriks kovarian:

  • Simetris: σᵢⱼ = σⱼᵢ (kovarian A ke B = kovarian B ke A)
  • Diagonal utama: σᵢᵢ = σᵢ² (kovarian suatu saham dengan dirinya sendiri = variance)
  • Positif definite: Semua eigenvalue positif (syarat matematis untuk variance valid)

📝 Contoh Matriks Kovarian (3 Saham)

Misalkan Anda memiliki portofolio dengan 3 saham: ASII, BBCA, TLKM

ASII BBCA TLKM
ASII 0.00206 (σ²ASII) -0.00045 0.00012
BBCA -0.00045 0.00202 (σ²BBCA) -0.00038
TLKM 0.00012 -0.00038 0.00174 (σ²TLKM)

Bobot: w = [0.40, 0.35, 0.25]'

Perhitungan:

σ²p = w' × Σ × w

= [0.40, 0.35, 0.25] × Σ × [0.40, 0.35, 0.25]'

= 0.00098

σp = √0.00098 = 3.13%

6. The Opportunity Set

🎯 Apa itu Opportunity Set?

Opportunity Set adalah kumpulan SEMUA portofolio yang mungkin dapat dibentuk dari sekumpulan aset yang tersedia. Ini adalah "menu" semua pilihan investasi yang bisa Anda buat.

Misalnya: Jika Anda punya 10 saham, opportunity set mencakup:

  • Semua portofolio dengan 1 saham (10 portofolio)
  • Semua portofolio dengan 2 saham (45 portofolio)
  • Semua portofolio dengan 3 saham (120 portofolio)
  • ... dst sampai portofolio dengan 10 saham (1 portofolio)
  • Total: 2¹⁰ - 1 = 1,023 portofolio
Karakteristik Opportunity Set:
  1. Bentuk bulan sabit (crescent-shaped) di ruang risk-return
  2. Minimum Variance Frontier = batas kiri dari opportunity set (portofolio dengan risiko terendah untuk setiap level return)
  3. Global Minimum Variance Portfolio = titik paling kiri (portofolio dengan risiko ABSOLUT terendah)
  4. Efficient Frontier = bagian ATAS dari minimum variance frontier (portofolio yang layak dipilih)

🎯 Mengapa Opportunity Set Berbentuk Bulan Sabit?

Bentuk bulan sabit terjadi karena efek diversifikasi. Ketika aset-aset dengan korelasi < +1.0 digabungkan, risiko portfolio bisa lebih rendah dari rata-rata risiko aset-asetnya. Semakin rendah korelasi, semakin "melengkung" opportunity set ke kiri.

Jika korelasi semua aset = +1.0: Opportunity set berupa garis lurus (tidak ada efek diversifikasi)

Jika korelasi < +1.0: Opportunity set melengkung ke kiri (ada efek diversifikasi)

7. The Efficient Frontier

🎯 Apa itu Efficient Frontier?

Efficient Frontier adalah kumpulan portofolio yang memberikan return TERTINGGI untuk setiap tingkat risiko, ATAU risiko TERENDAH untuk setiap tingkat return.

Mengapa penting? Investor rational TIDAK AKAN memilih portofolio yang TIDAK efisien. Jika ada portofolio lain yang memberikan return lebih tinggi untuk risiko yang sama, mengapa memilih yang rendah?

Kriteria Efisiensi (Markowitz):

Sebuah portofolio TIDAK efisien jika:

  1. Ada portofolio lain dengan return lebih tinggi untuk risiko yang sama, ATAU
  2. Ada portofolio lain dengan risiko lebih rendah untuk return yang sama

🎯 Interpretasi Efficient Frontier

Setiap titik di efficient frontier mewakili portofolio OPTIMAL untuk level risiko tertentu:

  • Titik kiri (Minimum Variance Portfolio) = risiko terendah, return terendah
  • Titik kanan = risiko tertinggi, return tertinggi
  • Titik tengah = keseimbangan risiko-return

Di bawah efficient frontier = portofolia TIDAK efisien (return terlalu rendah untuk risikonya)

Di atas efficient frontier = TIDAK MUNGKIN dicapai dengan kombinasi aset yang ada

💡 Insight: efficient Frontier untuk Setiap Investor

Semua investor rational akan memilih portofolio DI efficient frontier, tergantung toleransi risiko mereka:

  • Investor risk-averse → memilih portofolio di kiri efficient frontier (risiko rendah, return rendah)
  • Investor risk-neutral → memilih portofolio di tengah efficient frontier
  • Investor risk-seeking → memilih portofolio di kanan efficient frontier (risiko tinggi, return tinggi)

Ini adalah konsep "segitiga pembatas" (separating theorem) yang menjadi dasar CAPM.

8. Diversification Effects

🎯 Apa itu Diversification?

Diversifikasi adalah strategi menggabungkan berbagai aset dalam portofolio untuk mengurangi risiko TANPA mengurangi expected return. Ini adalah satu-satunya "free lunch" dalam investasi (Markowitz, 1952).

Rumus 12: Risk Reduction via Diversification
σ²p = (1/N)σ̄² + ((N-1)/N)Cov̄

Untuk equal-weighted portfolio (N saham, masing-masing bobot 1/N)

Keterangan:

  • σ̄² = Rata-rata variance semua saham
  • Cov̄ = Rata-rata kovarian semua pasangan saham
  • N = Jumlah saham

🎯 Interpretasi Rumus Diversification

Rumus ini memiliki 2 komponen:

  1. (1/N)σ̄² = Risiko spesifik (unsystematic risk) yang BISA dihilangkan dengan diversifikasi
  2. ((N-1)/N)Cov̄ = Risiko sistematis (systematic risk) yang TIDAK BISA dihilangkan

Ketika N → ∞:

  • (1/N)σ̄² → 0 (risiko spesifik hilang)
  • ((N-1)/N)Cov̄ → Cov̄ (risiko sistematis tetap ada)

Artinya: Diversifikasi hanya bisa menghilangkan risiko yang spesifik pada satu saham (misal: manajemen buruk, skandal, dll), tapi TIDAK BISA menghilangkan risiko pasar secara keseluruhan (misal: resesi global, pandemi, krisis keuangan).

💡 Dua Jenis Risiko

Risiko Definisi Bisa Diversifikasi? Contoh
Unsystematic Risk (Spesifik/Idiosyncratic) Risiko yang spesifik pada satu perusahaan atau sektor ✅ YA Kebangkrutan, skandal, manajemen buruk
Systematic Risk (Market/Wide) Risiko yang mempengaruhi SELURUH pasar ❌ TIDAK Resesi, inflasi, kenaikan suku bunga, pandemi

📝 Contoh Efek Diversifikasi

Data: Rata-rata variance (σ̄²) = 0.035, Rata-rata kovarian (Cov̄) = 0.01

N (Jumlah Saham) σ²p σp Risk Reduction Interpretasi
1 0.035 18.71% 0% Tanpa diversifikasi
2 0.0225 15.00% 19.8% Pengurangan signifikan
5 0.015 12.25% 34.6% Diversifikasi cukup baik
10 0.0125 11.18% 40.2% Diversifikasi optimal untuk banyak investor
20 0.01125 10.61% 43.3% Pengurangan mulai melambat
50 0.0105 10.25% 45.2% Hampir mencapai batas
100 0.01025 10.12% 45.9% Hampir tidak ada pengurangan lagi
∞ 0.01 10.00% 46.5% Batas maksimum diversifikasi

Interpretasi:

  • Dari 1 saham ke 10 saham: risiko turun 40.2% (pengurangan BESAR)
  • Dari 10 saham ke 100 saham: risiko turun hanya 5.7% (pengurangan KECIL)
  • Kesimpulan: Diversifikasi paling efektif di awal (1-10 saham). Setelah itu, manfaatnya semakin berkurang.

🧊 Analogi Sederhana

Bayangkan Anda membawa payung untuk melindungi dari hujan:

  • 1 payung = melindungi dari hujan lokal (risiko spesifik)
  • 10 payung = tetap basah saat hujan deras di seluruh kota (risiko sistematis)

Diversifikasi seperti membawa banyak payung: melindungi dari hujan lokal, tapi tidak dari hujan di seluruh kota.

Astra (ASII) 15% 60%
BCA (BBCA) 12% 40%

📝 Perhitungan Manual:

E(Rp) = w₁ × E(R₁) + w₂ × E(R₂)

E(Rp) = 0.60 × 15% + 0.40 × 12%

E(Rp) = 9% + 4.8% = 13.8%

=0.60*0.15 + 0.40*0.12

Hasil: 13.8%

Interpretasi: Jika Anda menginvestasikan 60% ke ASII dan 40% ke BBCA, return yang diharapkan adalah 13.8% per tahun.

Contoh 2: Portfolio Variance & Standard Deviation (2 Saham)

📊 Data:

Saham σ² (Variance) σ (Std Dev)
ASII 0.04 20%
BBCA 0.025 15.81%
Korelasi (ρ) 0.30

📝 Perhitungan Manual:

σ²p = w₁²σ₁² + w₂²σ₂² + 2w₁w₂ρ₁₂σ₁σ₂

σ²p = (0.60)²(0.04) + (0.40)²(0.025) + 2(0.60)(0.40)(0.3)(0.20)(0.1581)

σ²p = 0.0144 + 0.004 + 0.00456 = 0.02296

σp = √0.02296 = 15.15%

💻 Rumus Excel:

Variance:

=(0.6^2*0.04)+(0.4^2*0.025)+2*0.6*0.4*0.3*0.2*0.1581

Standard Deviation:

=SQRT((0.6^2*0.04)+(0.4^2*0.025)+2*0.6*0.4*0.3*0.2*0.1581)

Hasil: σp = 15.15%

Interpretasi: Risiko portfolio (15.15%) LEBIH RENDAH dari rata-rata risiko aset (18.32%). Ini membuktikan diversifikasi bekerja karena korelasi positif yang rendah (0.3).

Contoh 3: Minimum Variance Portfolio (2 Saham)

📝 Rumus Bobot Optimal:

w₁* = (σ₂² - σ₁₂) / (σ₁² + σ₂² - 2σ₁₂)
w₂* = 1 - w₁*

📝 Perhitungan:

w₁* = (0.025 - (-0.00045)) / (0.04 + 0.025 - 2(-0.00045))

w₁* = 0.02545 / 0.0659 = 38.62%

w₂* = 1 - 0.3862 = 61.38%

💻 Rumus Excel:

=(0.025-(-0.00045))/(0.04+0.025-2*(-0.00045))

Hasil: w₁* = 38.62%, w₂* = 61.38%

Interpretasi: Untuk mencapai risiko TERENDAH, Anda harus mengalokasikan 38.62% ke ASII dan 61.38% ke BBCA. Portofolio ini memiliki risiko lebih rendah dari kedua aset secara individual.

💡 Key Takeaways (Kesimpulan Utama)

  1. Expected Return adalah rata-rata tertimbang dari return individual — tidak bisa melebihi return aset terbaik
  2. Risk (σ) mengukur penyebaran return dari expected value — semakin tinggi σ, semakin tidak pasti hasilnya
  3. Covariance/Correlation mengukur hubungan antar return — korelasi rendah = diversifikasi efektif
  4. Diversification mengurangi risiko TANPA mengurangi expected return — ini "free lunch" dalam investasi
  5. Efficient Frontier adalah kumpulan portofolio optimal — investor rational hanya memilih dari sini
  6. Minimum Variance Portfolio adalah portofolio dengan risiko terendah — titik paling kiri di efficient frontier
  7. Risiko spesifik bisa dihilangkan dengan diversifikasi, risiko sistematis tidak bisa
