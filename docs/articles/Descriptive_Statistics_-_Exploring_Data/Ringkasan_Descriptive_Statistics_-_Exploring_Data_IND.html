Statistik Deskriptif: Menjelajahi Data menggunakan Stata

Artikel ini memberikan ringkasan komprehensif dari teknik-teknik yang dibahas dalam Panduan Penelitian Universitas Princeton “Descriptive Statistics – Exploring Data using Stata.” Panduan ini memandu pengguna melalui serangkaian perintah Stata yang memungkinkan peneliti untuk memeriksa struktur kumpulan data, mendapatkan statistik ringkasan, memeriksa definisi variabel, dan menghasilkan tabel frekuensi serta tabel silang. Setiap bagian di bawah ini mencerminkan organisasi panduan, menyoroti perintah kunci, menjelaskan output, dan memberikan tips praktis untuk menerapkan alat-alat ini pada data Anda sendiri.

1. Pendahuluan

Panduan ini dimulai dengan memuat kumpulan data bawaan nlsw88, yang berisi informasi dari Survei Longitudinal Nasional Wanita tahun 1988. Perintah sysuse nlsw88, clear membawa data ke memori dan menghapus kumpulan data sebelumnya. Pengguna diingatkan bahwa untuk analisis pribadi, kumpulan data dapat dibuka melalui File → Open → file .dta Anda atau dengan menggunakan perintah use dengan jalur file.

Tujuan panduan ini adalah untuk mengamiliarkan analisis dengan alat deskriptif penting dalam Stata: describe, summarize (atau singkatannya su), codebook, keluarga tab, tabstat, dan table. Penguasaan perintah-perintah ini memungkinkan analisis data eksploratif (EDA) yang cepat namun menyeluruh sebelum beralih ke pemodelan atau pengujian hipoteza.

2. Statistik Deskriptif (describe)

Perintah describe memberikan gambaran singkat tentang dimensi kumpulan data, nama variabel, tipe penyimpanan, format tampilan, dan label variabel. Setelah memuat nlsw88, mengetik describe menghasilkan tabel yang serupa dengan yang ditunjukkan di bawah ini.

Interpretasi

  • Observasi (2,246) – jumlah baris dalam kumpulan data.
  • Variabel (17) – jumlah kolom.
  • Tipe penyimpanan – menunjukkan cara Stata menyimpan setiap variabel secara internal (int, byte, float, dst.). Memahami tipe penyimpanan membantu memperkirakan penggunaan memori dan rentang nilai yang diperbolehkan.
  • Format tampilan – mengontrol cara nilai muncul saat dicetak atau dilihat. Sebagai contoh, %9.0g untuk wage berarti lebar total sembilan karakter menggunakan format umum yang menyesuaikan dengan magnitudo angka.
