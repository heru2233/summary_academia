Introduction

This guide provides a step‑by‑step walkthrough of how to explore and summarize data using Stata. The focus is on descriptive statistics, which allow the researcher to understand the shape, central tendency, dispersion, and relationships among variables before moving on to inferential analysis. The tutorial uses the built‑in dataset nlsw88 (National Longitudinal Survey of Women, 1988 extract) and demonstrates a series of Stata commands: describe, summarize (or its abbreviation su), codebook, frequency commands (tab, tab1, crosstab), and two customized table commands (tabstat and table). Each section explains the purpose of the command, shows the exact syntax, presents the output that Stata returns, and offers an interpretation of the results. By following the examples, users can replicate the analysis on their own datasets stored as .dta files.

Descriptive Statistics (describe)

Overview

The describe command provides a concise snapshot of the dataset’s structure: the number of observations, the number of variables, the storage type, display format, and variable labels for each column. This information is essential for verifying that the data have been imported correctly and for planning subsequent manipulations.

To load the example data and run describe, the user types:

sysuse nlsw88, clear
describe

Stata returns the following table (truncated for readability):

Interpretation of Storage Types and Display Formats

The output shows that the dataset contains 2,246 observations and 17 variables. Storage types reveal the underlying data format: int for integer IDs, byte for small‑integer categorical variables (e.g., race, married), and float for continuous variables with decimal precision (e.g., wage, ttl_exp, tenure). The display format (e.g., %9.0g) controls how Stata presents numeric values in the output window; a width of nine characters with a general format ensures readability without unnecessary trailing zeros. Value labels (e.g., racelbl, marlbl) map numeric codes to meaningful categories, which is crucial for interpreting tabulations and graphs.

Basic summarize

The summarize command (abbreviated su) computes univariate statistics: number of non‑missing observations, mean, standard deviation, minimum, and maximum. This provides a quick numerical profile of each variable.

The percentile columns show the distribution shape. For age, the median (39) is close to the mean (39.15), indicating near symmetry; the positive skewness of 0.20 suggests a slight right‑tail. Conditional summarize

Users can restrict the calculation to a subset of observations using an if qualifier. For example, to obtain summary statistics for age among married individuals:

su age if married == 1

Stata returns:

VariableObsMeanStd. dev.MinMax
age1,44239.11653.0660583445

The mean age of married respondents is virtually identical to the overall mean, suggesting that marital status is not strongly associated with age in this sample.

Summarize a list or range of variables

To obtain statistics for several variables at once, list them after su. For a contiguous range, use the hyphen notation:

su age race occupation union wage

or

su idcode-married

Both commands produce a compact table with the requested variables.

Grouped summarize

The by prefix allows separate summaries for each level of a categorical variable. For instance, to examine grade and wage across occupations:

by occupation, sort: summarize grade wage

Stata iterates through each occupation category, producing a block of statistics for each. A fragment of the output is shown below:

Frequency Tables (tab, tab1, crosstab)

One‑way frequency tables

The tab command creates frequency distributions for categorical variables. For the marital status variable:

tab married

Stata returns:

MarriedFreq.PercentCum.
Single80435.8035.80
Married1,44264.20100.00
Total2,246100.00

Thus, 64.2 % of the sample is married. Adding the nolabel option shows the underlying numeric codes (0 = single, 1 = married).

Tab with plot and sorting

To visualize the distribution of occupations with a bar plot and order categories by frequency:

tab occupation, plot sort

Stata produces a table where each occupation is accompanied by a histogram‑style bar made of asterisks. The most frequent occupation is Sales (726 observations), followed by Professional/Technical (317) and Laborers (286). The visual aid helps users spot dominant categories at a glance.

Tab1 for multiple variables

When the researcher needs frequencies for several variables simultaneously, tab1 automates the process:

tab1 married south race

Stata outputs three separate tables, one for each variable. For race the table is:
