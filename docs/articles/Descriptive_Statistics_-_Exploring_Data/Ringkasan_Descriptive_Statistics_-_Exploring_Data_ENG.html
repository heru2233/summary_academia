Descriptive Statistics: Exploring Data using Stata

This article provides a comprehensive summary of the techniques covered in the Princeton University Research Guide “Descriptive Statistics – Exploring Data using Stata.” The guide walks users through a series of Stata commands that allow researchers to inspect the structure of a dataset, obtain summary statistics, examine variable definitions, and produce frequency and cross‑tabulation tables. Each section below mirrors the guide’s organization, highlights the key commands, explains the output, and offers practical tips for applying the tools to your own data.

1. Introduction

The guide begins by loading the built‑in nlsw88 dataset, which contains information from the 1988 National Longitudinal Survey of Women. The command sysuse nlsw88, clear brings the data into memory and clears any previous dataset. Users are reminded that for personal analyses the dataset can be opened via File → Open → your .dta file or by using the use command with a file path.

The purpose of the guide is to familiarize analysts with the essential descriptive tools in Stata: describe, summarize (or its abbreviation su), codebook, tab family, tabstat, and table. Mastery of these commands enables a quick yet thorough exploratory data analysis (EDA) before moving on to modelling or hypothesis testing.

2. Descriptive Statistics (describe)

The describe command provides a snapshot of the dataset’s dimensions, variable names, storage types, display formats, and variable labels. After loading nlsw88, typing describe yields a table similar to the one shown below.

Interpretation

  • Observations (2,246) – number of rows in the dataset.
  • Variables (17) – number of columns.
  • Storage type – indicates how Stata stores each variable internally (int, byte, float, etc.). Understanding storage type helps anticipate memory usage and the range of permissible values.
  • Display format – controls how values appear when printed or viewed. For example, %9.0g for wage means a total width of nine characters using a general format that adapts to the magnitude of the number.
  • Value label – attaches meaningful strings to numeric codes (e.g., racelbl maps 1→White, 2→Black, 3→Other).

The guide emphasizes that describe is the first step in any EDA workflow because it reveals potential issues such as unexpected storage types, missing value labels, or variables that should be recoded.

3.3 Conditional Summaries

The guide illustrates how to restrict summaries to subsets using the if qualifier. For example, su age if married == 1 returns statistics for married individuals only.

VariableObsMeanStd. dev.MinMax
age1,44239.11653.0660583445

The mean age of married respondents is 39.12 years, virtually identical to the overall mean, suggesting marriage is not strongly associated with age in this sample.

To obtain statistics separately for categories of another variable, combine by with summarize. The example by occupation, sort: summarize grade wage produces a separate table for each occupation.
