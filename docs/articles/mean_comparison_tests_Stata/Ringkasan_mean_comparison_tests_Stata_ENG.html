Overview of Mean‑Comparison Tests in Stata

The ttest command in Stata performs a variety of Student’s t‑tests for comparing means. It handles one‑sample tests against a hypothesized constant, two‑sample tests for independent (unpaired) groups, and paired tests for dependent observations. The command also offers an immediate form (ttesti) that works with summary statistics rather than variables. This article summarizes the syntax, options, illustrative examples, stored results, and underlying formulas as presented in the official Stata manual for ttest and ttesti.

Syntax Overview

The general syntax of ttest can be broken down into four main forms: one‑sample, two‑sample using groups, two‑sample using variables, and paired. Each form accepts a set of optional modifiers that control variance assumptions, confidence level, and output details.

One‑sample t test

ttest varname == # [if] [in] [, level(#)]

Tests whether the mean of varname equals the constant #. The level() option sets the confidence level for the interval (default 95%).

Two‑sample t test using groups

ttest varname [if] [in], by(groupvar) [options1]

by(groupvar) is required and defines the two groups to be compared. The options1 block includes:

  • reverse – reverses the order of the mean difference.
  • unpaired – treats the data as independent samples (default when by() is used).
  • unequal – does not assume equal variances.
  • welch – uses Welch’s approximation for degrees of freedom (implies unequal).
  • level(#) – sets the confidence level.

Two‑sample t test using variables

ttest varname1 == varname2 [if] [in], [unpaired] [unequal] [welch] [level(#)]

When the two samples are stored in separate variables, the unpaired flag signals an independent‑samples test; omitting it yields a paired test.

Paired t test

ttest varname1 == varname2 [if] [in] [, level(#)]

By default, ttest assumes a paired design when the syntax uses two variable names without unpaired.

Immediate form

ttesi #obs #mean #sd #val [, level(#)] – one‑sample immediate.
ttesi #obs1 #mean1 #sd1 #obs2 #mean2 #sd2 [, options2] – two‑sample immediate, where options2 may include unequal, welch, and level().

Detailed Options

The following table enumerates the modifiers that can appear after the main command.

OptionDescription
by(groupvar)Defines the grouping variable for two‑sample tests; required for the group‑based syntax.
reverseReverses the subtraction order when computing the mean difference (useful for customizing the sign of the effect).
unpairedSpecifies that the two samples are independent; needed when the data are in separate variables.
unequalRelaxes the equal‑variance assumption; uses separate variance estimates.
welchApplies Welch’s formula for degrees of freedom; automatically sets unequal.
level(#)Sets the confidence level for the interval estimate (percentage). Default is 95.

Illustrative Examples

The manual provides a series of worked examples that demonstrate each variant of the command. Below we summarize the key points of each example, highlighting the Stata code, the output structure, and the substantive interpretation.

One‑sample t test (Example 1)

Using the 1978 automobile dataset, the mean miles‑per‑gallon (mpg) is tested against the hypothesized value of 20 mpg.

. use https://www.stata-press.com/data/r18/auto
. ttest mpg==20

The output table reports:

The two‑sided p‑value of 0.0576 indicates that, at the conventional 5 % level, we fail to reject the null hypothesis that the true mean equals 20 mpg, although the result is marginally significant.

Two‑sample t test using groups (Example 2)

An experiment compares fuel‑treated versus untreated cars. The grouping variable treated equals 1 for treated and 0 for untreated.

. ttest mpg, by(treated)

When the analyst relaxes the equal‑variance assumption and invokes Welch’s approximation:

. ttest mpg, by(treated) welch

The resulting table is nearly identical, with a slightly adjusted degrees of freedom (23.25) and p‑value (0.1666). The conclusion remains unchanged.

Two‑sample t test using variables (Example 3)

When the two samples are stored in separate variables (mpg1 and mpg2), the command is:

. use https://www.stata-press.com/data/r18/fuel
. ttest mpg1==mpg2, unpaired

The output mirrors that of Example 2 because the underlying data are the same; the only difference is the labeling of the groups (mpg1 vs. mpg2).

Stored Results

After execution, ttest and ttesti store a variety of scalars in the r() class, enabling downstream programming. The key stored results are:

ResultDescription
r(N_1)Sample size of the first group or variable.
r(sd_1)Standard deviation of the first group.
r(N_2)Sample size of the second group (if applicable).
r(sd_2)Standard deviation of the second group.
r(mu_1)Mean of the first group.
r(mu_2)Mean of the second group.
r(se)Estimated standard error of the mean difference.
r(t)t statistic.
r(df_t)Degrees of freedom used for the test.
r(p)Two‑sided p‑value.
r(p_l)Lower one‑sided p‑value (Pr(T < t)).
r(p_u)Upper one‑sided p‑value (Pr(T > t)).
r(level)Confidence level used (percentage).
r(sd)Pooled standard deviation (when equal variances assumed).

These results can be accessed directly, for example:

. display "t = " r(t) ", p = " r(p)

Methods and Formulas

The manual provides the underlying mathematical expressions for each variant of the test.

One‑sample test

For testing \(H_0:\mu=\mu_0\) with unknown variance:

\[ t = \frac{\bar{x}-\mu_0}{s/\sqrt{n}} \]

where \(\bar{x}\) is the sample mean, \(s\) the sample standard deviation, and \(n\) the sample size. Under \(H_0\), \(t\sim t_{n-1}\).

Two‑sample test with equal variances

When \(\sigma_x^2=\sigma_y^2\) is assumed:

\[ t = \frac{\bar{x}-\bar{y}} {\sqrt{s_p^2\left(\frac{1}{n_x}+\frac{1}{n_y}\right)}} \]

with pooled variance

\[ s_p^2 = \frac{(n_x-1)s_x^2+(n_y-1)s_y^2}{n_x+n_y-2} \]

and degrees of freedom \(df=n_x+n_y-2\).

Two‑sample test with unequal variances (Satterthwaite)

When variances are not assumed equal:

\[ t = \frac{\bar{x}-\bar{y}} {\sqrt{\frac{s_x^2}{n_x}+\frac{s_y^2}{n_y}}} \]

The approximate degrees of freedom are given by Satterthwaite’s formula:

\[ \nu = \frac{\left(\frac{s_x^2}{n_x}+\frac{s_y^2}{n_y}\right)^2} {\frac{(s_x^2/n_x)^2}{n_x-1}+\frac{(s_y^2/n_y)^2}{n_y-1}} \]

Welch’s approximation

Welch (1947) proposes a slightly different df expression:

\[ \nu = -2 + \frac{\left(\frac{s_x^2}{n_x}+\frac{s_y^2}{n_y}\right)^2} {\frac{(s_x^2/n_x)^2}{n_x+1}+\frac{(s_y^2/n_y)^2}{n_y+1}} \]

Specifying welch invokes this formula.

Paired test

For paired observations, define \(d_i = x_i - y_i\). Let \(\bar{d}\) be the mean of the differences and \(s_d\) their standard deviation. Then

\[ t = \frac{\bar{d}}{s_d/\sqrt{n}} \]

with \(df=n-1\).

Conclusion

The ttest family in Stata provides a flexible and well‑documented framework for conducting mean‑comparison tests. By mastering the syntax options—by(), unequal, welch, level(), and the immediate forms—users can adapt the test to a wide range of experimental and observational designs. The stored results facilitate automation and reporting, while the underlying formulas ensure that the tests are grounded in classical statistical theory. Whether comparing a single sample to a benchmark, evaluating two independent groups, or analyzing paired measurements, ttest remains a cornerstone tool for empirical research in Stata.
