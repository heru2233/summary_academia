1. Kombinasi Dua Aset Berisiko

1.1 Expected Return Portofolio

Expected return pada portofolio yang terdiri dari dua aset berisiko adalah rata-rata tertimbang sederhana dari expected return masing-masing aset, dengan bobot yang berjumlah 1. Hubungan ini bersifat linear dan berlaku terlepas dari korelasi antar aset. Expected return portofolio merupakan komponen paling sederhana dalam analisis portofolio karena tidak melibatkan suku interaksi—bersifat murni aditif.

Dalam praktiknya, kombinasi dua aset akan menghasilkan expected return yang terletak di antara expected return kedua aset individual ketika kedua bobot bernilai positif dan berjumlah 1. Jika short sales diperbolehkan dan bobot dapat bernilai negatif atau melebihi 1, expected return portofolio dapat melampaui rentang expected return aset individual.

Expected Return Portofolio
\[ \bar{R}_P = X_A \bar{R}_A + X_B \bar{R}_B \]

Simbol: $\bar{R}_P$ adalah expected return portofolio; $X_A$ adalah proporsi portofolio yang diinvestasikan pada aset A; $X_B$ adalah proporsi pada aset B; $\bar{R}_A$ dan $\bar{R}_B$ masing-masing adalah expected return aset A dan B. Kendala $X_A + X_B = 1$ memastikan investasi penuh. Substitusi $X_B = 1 - X_A$ menghasilkan $\bar{R}_P = X_A \bar{R}_A + (1 - X_A) \bar{R}_B$.

Interpretasi: Expected return portofolio meningkat secara linear terhadap $X_A$ ketika $\bar{R}_A > \bar{R}_B$. Untuk setiap kenaikan satu satuan $X_A$, expected return portofolio berubah sebesar $(\bar{R}_A - \bar{R}_B)$.

Penggunaan praktis: Rumus ini digunakan untuk menghitung expected return untuk setiap alokasi yang diusulkan antara dua aset. Ini adalah langkah pertama dalam menyusun kurva kemungkinan portofolio.

Asumsi: Expected return $\bar{R}_A$ dan $\bar{R}_B$ diasumsikan diketahui atau diestimasi. Rumus ini tidak memperhitungkan estimation error pada input tersebut.

Example

Colonel Motors (C): $\bar{R}_C = 14\%$, $\sigma_C = 6\%$; Separated Edison (S): $\bar{R}_S = 8\%$, $\sigma_S = 3\%$. Untuk $X_C = 0.4$, $\bar{R}_P = 0.4(14) + 0.6(8) = 10.4\%$.

Key Insight

Expected return portofolio selalu merupakan rata-rata tertimbang dari expected return aset individual. Risiko, bagaimanapun, tidak selalu merupakan rata-rata tertimbang—asimetri ini merupakan fondasi manfaat diversifikasi.

Key Takeaways

  • Expected return portofolio adalah kombinasi linear dari expected return aset individual.
  • Bobot harus berjumlah 1 (kendala investasi penuh).
  • Rumus ini berlaku untuk semua nilai koefisien korelasi antara dua aset.

1.2 Variance dan Standard Deviation Portofolio

Standard deviation portofolio dua aset secara umum bukanlah rata-rata tertimbang dari standard deviation masing-masing aset. Sebaliknya, rumus ini mencakup suku hasil kali silang yang melibatkan covariance antara kedua aset. Ini adalah fakta matematis kritis yang membuat diversifikasi berpotensi menguntungkan: ketika return aset tidak bergerak secara sempurna bersamaan, risiko portofolio dapat lebih kecil daripada rata-rata tertimbang risiko individual.

Suku covariance $\sigma_{AB}$ dapat dinyatakan sebagai $\rho_{AB} \sigma_A \sigma_B$, di mana $\rho_{AB}$ adalah koefisien korelasi. Koefisien korelasi terletak di antara $-1$ dan $+1$, dan nilainya menentukan sejauh mana diversifikasi mengurangi risiko. Semakin rendah korelasi, semakin besar potensi pengurangan risiko.

Standard Deviation Portofolio (Bentuk Umum)
\[ \sigma_P = \left[ X_A^2 \sigma_A^2 + X_B^2 \sigma_B^2 + 2 X_A X_B \sigma_{AB} \right]^{1/2} \]

Simbol: $\sigma_P$ adalah standard deviation portofolio; $\sigma_A^2$ dan $\sigma_B^2$ adalah variance aset A dan B; $\sigma_{AB}$ adalah covariance antara A dan B. Dengan menggunakan $X_B = 1 - X_A$ dan $\sigma_{AB} = \rho_{AB} \sigma_A \sigma_B$, diperoleh:

Standard Deviation Portofolio (Bentuk Diperluas)
\[ \sigma_P = \left[ X_A^2 \sigma_A^2 + (1 - X_A)^2 \sigma_B^2 + 2 X_A (1 - X_A) \rho_{AB} \sigma_A \sigma_B \right]^{1/2} \]

Interpretasi: Standard deviation portofolio bergantung pada tiga komponen: variance masing-masing aset dibobot oleh kuadrat bobot portofolionya, dan suku covariance. Ketika $\rho_{AB} = +1$, ekspresi ini menyederhanakan menjadi $\sigma_P = X_A \sigma_A + (1 - X_A) \sigma_B$, yang merupakan rata-rata tertimbang—tidak ada manfaat diversifikasi. Ketika $\rho_{AB} = -1$, ekspresi ini menyederhanakan menjadi $\sigma_P = |X_A \sigma_A - (1 - X_A) \sigma_B|$, yang dapat dibuat nol pada bobot tertentu. Untuk korelasi antara ($-1 < \rho < +1$), standard deviation portofolio terletak di antara dua ekstrem ini.

Penggunaan praktis: Rumus ini digunakan untuk menghitung risiko portofolio untuk setiap alokasi dan estimasi korelasi yang diberikan. Ini penting untuk menelusuri kurva kemungkinan portofolio dan mengidentifikasi portofolio variance minimum.

Asumsi: Variance dan covariance (atau korelasi) diasumsikan diketahui. Dalam praktik, keduanya diestimasi dari data historis, sehingga menimbulkan estimation error.

Example

Untuk Colonel Motors ($\sigma_C = 6\%$) dan Separated Edison ($\sigma_S = 3\%$), dengan $\rho_{CS} = 0$ dan $X_C = 0.2$: $\sigma_P = [0.2^2(36) + 0.8^2(9) + 2(0.2)(0.8)(0)(6)(3)]^{1/2} = [1.44 + 5.76]^{1/2} = 2.68\%$. Perhatikan bahwa ini lebih rendah dari $\sigma_S = 3\%$ dan $\sigma_C = 6\%$, yang menunjukkan manfaat diversifikasi.

Analogy

Menggabungkan dua aset dengan korelasi tidak sempurna seperti mencampur dua bahan yang kadang saling meniadakan efek ekstremnya. Jika satu bahan kadang terlalu panas dan bahan lain terlalu dingin, mencampurnya menghasilkan suhu yang lebih konsisten dan moderat. Semakin tidak sinkron pergerakan kedua bahan, semakin stabil campurannya.

Key Insight

Standard deviation portofolio bukanlah rata-rata tertimbang dari standard deviation individual, kecuali dalam kasus khusus korelasi positif sempurna ($\rho = +1$). Untuk setiap $\rho < +1$, standard deviation portofolio lebih kecil daripada rata-rata tertimbang, dan perbedaan ini merupakan ukuran manfaat diversifikasi.

  • Risiko portofolio bergantung pada variance, covariance, dan bobot.
  • Korelasi yang lebih rendah menghasilkan pengurangan risiko yang lebih besar.
  • Koefisien korelasi terletak di antara $-1$ dan $+1$.

1.3 Kasus Khusus Korelasi

1.3.1 Korelasi Positif Sempurna ($\rho = +1$)

Ketika $\rho = +1$, kedua aset bergerak secara sempurna bersamaan. Standard deviation portofolio menyederhanakan menjadi rata-rata tertimbang: $\sigma_P = X_A \sigma_A + (1 - X_A) \sigma_B$. Baik risiko maupun return adalah kombinasi linear dari nilai aset individual. Semua kombinasi dari dua aset terletak pada garis lurus yang menghubungkan kedua aset dalam ruang expected return–standard deviation. Tidak ada pengurangan risiko dari diversifikasi—tidak ada yang diperoleh dengan memegang kedua aset dibandingkan hanya satu.

Dalam praktiknya, korelasi positif sempurna sangat jarang terjadi, tetapi beberapa aset mungkin memiliki korelasi yang sangat tinggi (misalnya, dua saham dalam industri yang sama dengan kapitalisasi pasar serupa). Dalam kasus seperti ini, manfaat diversifikasi sangat kecil.

Standard Deviation Portofolio ($\rho = +1$)
\[ \sigma_P = X_A \sigma_A + (1 - X_A) \sigma_B \]

Interpretasi: Hubungan antara $\bar{R}_P$ dan $\sigma_P$ adalah linear. Menyelesaikan $X_A$ dari $\sigma_P$ dan mensubstitusikannya ke dalam $\bar{R}_P$ menghasilkan garis lurus yang menghubungkan kedua aset. Semua portofolio terletak pada garis ini; tidak ada portofolio yang menawarkan risiko lebih rendah daripada yang ditunjukkan garis.

Key Insight

Ketika $\rho = +1$, diversifikasi tidak memberikan manfaat apa pun. Investor sebaiknya memegang satu aset dengan trade-off risiko–return yang lebih baik.

1.3.2 Korelasi Negatif Sempurna ($\rho = -1$)

Ketika $\rho = -1$, kedua aset bergerak dalam arah yang berlawanan secara sempurna. Standard deviation portofolio menyederhanakan menjadi $\sigma_P = |X_A \sigma_A - (1 - X_A) \sigma_B|$. Ekspresi ini dapat dibuat nol dengan memilih $X_A = \sigma_B / (\sigma_A + \sigma_B)$. Pada bobot spesifik ini, risiko kedua aset saling meniadakan secara sempurna, menghasilkan portofolio dengan risiko nol. Ini adalah hasil diversifikasi yang paling kuat: penghapusan seluruh risiko dari kombinasi dua aset yang masing-masing berisiko.

Dalam praktiknya, korelasi negatif sempurna sama jarangnya dengan korelasi positif sempurna. Namun, beberapa aset mungkin memiliki korelasi negatif (misalnya, emas dan ekuitas pada rezim pasar tertentu), yang memberikan pengurangan risiko substansial.

Standard Deviation Portofolio ($\rho = -1$)
\[ \sigma_P = |X_A \sigma_A - (1 - X_A) \sigma_B| \]

Interpretasi: Hubungan antara $\bar{R}_P$ dan $\sigma_P$ terdiri dari dua segmen linear yang bertemu pada titik di mana $\sigma_P = 0$. Untuk bobot di bawah titik risiko nol, satu ekspresi berlaku; untuk bobot di atasnya, ekspresi lainnya berlaku. Portofolio risiko nol selalu melibatkan investasi positif pada kedua sekuritas ketika $\sigma_A > 0$ dan $\sigma_B > 0$.

Example

Untuk Colonel Motors ($\sigma_C = 6\%$) dan Separated Edison ($\sigma_S = 3\%$) dengan $\rho = -1$, portofolio risiko nol terjadi pada $X_C = 3/(3+6) = 1/3$. Pada $X_C = 1/3$, $\sigma_P = |(1/3)(6) - (2/3)(3)| = |2 - 2| = 0\%$. Expected return-nya adalah $\bar{R}_P = (1/3)(14) + (2/3)(8) = 10\%$.

Key Insight

Korelasi negatif sempurna memungkinkan penghapusan total risiko portofolio. Ini adalah batas teoretis atas dari manfaat diversifikasi. Bahkan korelasi negatif yang sederhana dapat mengurangi risiko secara substansial.

1.3.3 Korelasi Nol ($\rho = 0$)

Ketika $\rho = 0$, suku covariance hilang, dan standard deviation portofolio menjadi $\sigma_P = [X_A^2 \sigma_A^2 + (1 - X_A)^2 \sigma_B^2]^{1/2}$. Ini adalah hubungan melengkung dalam ruang expected return–standard deviation, terletak di antara kasus ekstrem $\rho = +1$ dan $\rho = -1$. Portofolio variance minimum terjadi pada bobot spesifik yang dapat ditemukan dengan kalkulus.

Bobot Portofolio Variance Minimum ($\rho = 0$)
\[ X_A^* = \frac{\sigma_B^2}{\sigma_A^2 + \sigma_B^2} \]

Interpretasi: Bobot yang meminimalkan variance portofolio ketika $\rho = 0$ sebanding dengan variance aset lainnya. Aset dengan variance lebih rendah menerima bobot lebih besar dalam portofolio variance minimum.

Example

Untuk Colonel Motors ($\sigma_C = 6\%$) dan Separated Edison ($\sigma_S = 3\%$) dengan $\rho = 0$: $X_C^* = 9/(36+9) = 9/45 = 0.20$. Pada $X_C = 0.20$, $\sigma_P = [0.04(36) + 0.64(9)]^{1/2} = [1.44 + 5.76]^{1/2} = 2.68\%$.

1.3.4 Korelasi Antara ($\rho = 0.5$)

Ketika $\rho = 0.5$, korelasi positif tetapi tidak sempurna. Kurva kemungkinan portofolio terletak di antara kurva $\rho = 0$ dan $\rho = +1$. Untuk contoh Colonel Motors dan Separated Edison dengan $\rho = 0.5$, portofolio variance minimum terjadi pada $X_C = 0$ (100% pada Separated Edison), artinya tidak ada kombinasi dari kedua saham yang menghasilkan risiko lebih rendah daripada aset paling tidak berisiko sendirian. Ambang korelasi di bawah mana manfaat diversifikasi muncul adalah $\rho = \sigma_S / \sigma_C = 3/6 = 0.5$.

Bobot Portofolio Variance Minimum Umum
\[ X_A^* = \frac{\sigma_B^2 - \sigma_A \sigma_B \rho_{AB}}{\sigma_A^2 + \sigma_B^2 - 2 \sigma_A \sigma_B \rho_{AB}} \]

Simbol: $X_A^*$ adalah proporsi portofolio yang diinvestasikan pada aset A yang meminimalkan variance portofolio; $\sigma_A$ dan $\sigma_B$ adalah standard deviation aset A dan B; $\rho_{AB}$ adalah koefisien korelasi antara keduanya.

Interpretasi: Rumus ini memberikan bobot yang menghasilkan portofolio dengan risiko serendah mungkin untuk setiap korelasi yang diberikan. Ketika $\rho_{AB} = 0$, rumus ini menyederhanakan menjadi $X_A^* = \sigma_B^2 / (\sigma_A^2 + \sigma_B^2)$. Ketika $\rho_{AB} = \sigma_B / \sigma_A$, portofolio variance minimum adalah 100% pada aset B yang lebih tidak berisiko.

Penggunaan praktis: Rumus ini digunakan untuk mengidentifikasi alokasi risiko minimum antara dua aset, yang merupakan titik referensi kunci pada kurva kemungkinan portofolio.

  • $\rho = +1$: tidak ada manfaat diversifikasi; hubungan risiko–return linear.
  • $\rho = -1$: diversifikasi maksimum; portofolio risiko nol dimungkinkan.
  • $\rho = 0$: pengurangan risiko substansial; hubungan melengkung.
  • Untuk setiap $\rho < +1$, risiko portofolio lebih kecil daripada rata-rata tertimbang risiko individual.
  • Rumus bobot portofolio variance minimum berlaku umum untuk semua nilai korelasi.

2. Bentuk Kurva Kemungkinan Portofolio

Kurva kemungkinan portofolio menelusuri semua kombinasi dua aset dalam ruang expected return–standard deviation. Sifat geometris yang penting adalah bahwa bagian kurva di atas portofolio variance minimum bersifat cekung, sedangkan bagian di bawahnya bersifat cembung. Ini bukan artefak dari contoh spesifik, melainkan sifat umum dari semua masalah portofolio.

Untuk memahami alasannya, pertimbangkan kombinasi portofolio variance minimum (MV) dengan aset atau portofolio lain. Jika kurva cembung di atas MV, maka akan ada dua portofolio U dan V sehingga kombinasi U dan V terletak di bawah garis lurus yang menghubungkan keduanya. Tetapi ini mustahil karena kombinasi dua portofolio harus terletak pada atau di atas garis lurus yang menghubungkannya (garis tersebut berkorespondensi dengan $\rho = +1$). Oleh karena itu, kurva tidak mungkin cembung di atas MV—ia harus cekung. Demikian pula, kurva di bawah MV harus cembung.

Sifat geometris ini memiliki implikasi penting bagi bentuk efficient frontier: efficient frontier, yang merupakan bagian atas dari kurva kemungkinan portofolio, selalu cekung.

Key Insight

Kurva kemungkinan portofolio cekung di atas portofolio variance minimum dan cembung di bawahnya. Ini adalah sifat matematis yang diperlukan yang muncul dari fakta bahwa kombinasi dua portofolio tidak dapat menghasilkan lebih banyak risiko daripada garis lurus yang menghubungkannya.

  • Kurva kemungkinan portofolio cekung di atas portofolio variance minimum.
  • Kurva cembung di bawah portofolio variance minimum.
  • Sifat-sifat geometris ini mengikuti sifat fundamental variance portofolio.

3. Efficient Frontier Tanpa Short Sales

Efficient frontier adalah himpunan portofolio yang mendominasi semua portofolio lain dalam hal menawarkan expected return tertinggi untuk tingkat risiko tertentu, atau risiko terendah untuk tingkat expected return tertentu. Dalam alam semesta yang terdiri dari banyak aset berisiko, ketika short sales tidak diperbolehkan, efficient frontier adalah selubung atas dari semua portofolio yang layak, memanjang dari portofolio variance minimum global hingga portofolio return maksimum.

Untuk mengonstruksi efficient frontier, mulailah dengan memplot semua portofolio yang mungkin (semua kombinasi semua aset dalam semua bobot yang mungkin) dalam ruang expected return–standard deviation. Kemudian eliminasi portofolio yang didominasi oleh portofolio lain: suatu portofolio didominasi jika terdapat portofolio lain dengan return lebih tinggi untuk risiko yang sama, atau risiko lebih rendah untuk return yang sama. Portofolio yang tersisa membentuk himpunan efisien. Portofolio variance minimum global adalah portofolio dengan risiko terendah di antara semua portofolio yang layak. Portofolio return maksimum biasanya adalah aset tunggal dengan expected return tertinggi.

Efficient frontier bersifat cekung, sebagaimana ditetapkan pada bagian sebelumnya. Ia tidak dapat mengandung wilayah cembung karena setiap dua portofolio pada frontier, ketika dikombinasikan, harus terletak pada atau di atas garis lurus yang menghubungkannya—dan jika frontier cembung, kombinasi akan terletak di bawah garis, yang mustahil.

Key Insight

Efficient frontier adalah selubung cekung dari semua portofolio yang layak, memanjang dari portofolio variance minimum global hingga portofolio return maksimum. Semua investor rasional yang menghindari risiko dan menyukai return yang lebih tinggi akan memilih portofolio pada frontier ini.

  • Efficient frontier terdiri dari semua portofolio yang tidak didominasi.
  • Ia memanjang dari portofolio variance minimum global hingga portofolio return maksimum.
  • Frontier bersifat cekung (tidak memiliki wilayah cembung).
  • Portofolio interior dan portofolio yang didominasi dikeluarkan.

4. Efficient Frontier dengan Short Sales Diperbolehkan

Short selling memungkinkan investor untuk mengambil posisi negatif dalam suatu sekuritas. Dalam konteks analisis portofolio, short selling diperlakukan sebagai kemampuan untuk menjual sekuritas tanpa memilikinya, menggunakan hasil penjualan untuk membeli sekuritas lain. Ini memungkinkan bobot portofolio menjadi negatif (untuk posisi pendek) atau lebih besar dari 1 (untuk posisi panjang dengan leverage).

Ketika short sales diperbolehkan, efficient frontier melampaui portofolio return maksimum. Seorang investor dapat menjual pendek sekuritas dengan expected return rendah dan menggunakan hasilnya (ditambah modal awal) untuk berinvestasi pada sekuritas dengan expected return tinggi, berpotensi mencapai expected return yang lebih tinggi daripada aset tunggal mana pun. Namun, ini disertai dengan risiko yang lebih tinggi secara sepadan. Efficient frontier dengan short sales yang diperbolehkan tetap cekung, tetapi tidak memiliki batas atas yang terbatas—ia berlanjut tanpa batas ke atas dan ke kanan.

Portofolio variance minimum tetap ada dan merupakan titik awal dari efficient frontier. Himpunan efisien, dengan short sales diperbolehkan, adalah bagian atas dari hiperbola (Merton, 1972).

Example

Dengan Colonel Motors ($\bar{R}_C = 14\%$, $\sigma_C = 6\%$) dan Separated Edison ($\bar{R}_S = 8\%$, $\sigma_S = 3\%$), $\rho = 0.5$, dan short sales diperbolehkan: jika $X_C = 2.0$ (200% pada Colonel Motors, dibiayai dengan menjual pendek Separated Edison pada $X_S = -1.0$), maka $\bar{R}_P = 2(14) + (-1)(8) = 20\%$ dan $\sigma_P = [4(36) + 1(9) + 2(2)(-1)(0.5)(6)(3)]^{1/2} = [144 + 9 - 36]^{1/2} = 10.82\%$.

Key Insight

Short sales memungkinkan investor mencapai expected return di luar aset tunggal mana pun, tetapi dengan risiko yang lebih tinggi secara proporsional. Efficient frontier menjadi hiperbola tanpa batas atas.

  • Short sales memungkinkan bobot negatif dan bobot lebih besar dari 1.
  • Efficient frontier tidak memiliki batas atas yang terbatas ketika short sales diperbolehkan.
  • Frontier tetap cekung dan dimulai dari portofolio variance minimum.
  • Sebagian besar investor institusional menghadapi kendala pada short selling.

5. Efficient Frontier dengan Riskless Lending and Borrowing

5.1 Menggabungkan Aset Bebas Risiko dengan Portofolio Berisiko

Kehadiran aset bebas risiko (dengan return $R_F$ dan $\sigma_F = 0$) secara dramatis menyederhanakan analisis portofolio. Ketika seorang investor dapat meminjamkan (berinvestasi pada aset bebas risiko) atau meminjam (menjual pendek aset bebas risiko) pada tingkat yang sama $R_F$, semua kombinasi aset bebas risiko dengan portofolio berisiko A terletak pada garis lurus dalam ruang expected return–standard deviation. Garis tersebut melewati $(0, R_F)$ dan $(\sigma_A, \bar{R}_A)$.

Persamaan garis ini adalah $\bar{R}_C = R_F + [(\bar{R}_A - R_F)/\sigma_A] \sigma_C$, di mana kemiringan $(\bar{R}_A - R_F)/\sigma_A$ adalah rasio imbalan-terhadap-risiko (Sharpe ratio) portofolio A. Investor dapat memilih titik mana pun pada garis ini dengan menyesuaikan proporsi kekayaan yang dialokasikan ke aset bebas risiko versus portofolio berisiko.

Kombinasi Aset Bebas Risiko dan Portofolio Berisiko
\[ \bar{R}_C = R_F + \frac{\bar{R}_A - R_F}{\sigma_A} \sigma_C \]

Simbol: $\bar{R}_C$ adalah expected return portofolio gabungan; $\sigma_C$ adalah standard deviation portofolio gabungan; $R_F$ adalah tingkat bebas risiko; $\bar{R}_A$ dan $\sigma_A$ adalah expected return dan standard deviation portofolio berisiko A.

Interpretasi: Hubungannya linear. Intercept-nya adalah $R_F$, dan kemiringannya adalah Sharpe ratio portofolio A. Untuk setiap tingkat risiko $\sigma_C$, expected return meningkat secara linear dengan kemiringan. Titik di sebelah kiri A berkorespondensi dengan lending (memegang sebagian aset bebas risiko); titik di sebelah kanan berkorespondensi dengan borrowing (leverage pada portofolio berisiko).

Penggunaan praktis: Rumus ini memungkinkan investor menghitung expected return untuk setiap tingkat risiko yang diinginkan ketika mencampur aset bebas risiko dengan portofolio berisiko.

5.2 Portofolio Titik Singgung dan Separation Theorem

Di antara semua portofolio berisiko yang mungkin, portofolio yang memaksimalkan kemiringan garis dari $R_F$ adalah portofolio titik singgung G—titik di mana sinar dari $R_F$ menyinggung efficient frontier aset berisiko. Semua investor, tanpa memandang preferensi risiko mereka, akan memegang portofolio aset berisiko yang sama (portofolio G) ketika mereka dapat meminjamkan dan meminjam pada tingkat bebas risiko yang sama. Ini adalah separation theorem: masalah pemilihan portofolio terpisah menjadi (1) mengidentifikasi portofolio berisiko optimal G (yang hanya bergantung pada karakteristik aset dan $R_F$, bukan pada preferensi investor) dan (2) memilih campuran antara G dan aset bebas risiko berdasarkan toleransi risiko individu.

Separation theorem adalah hasil yang kuat. Ini berarti komposisi optimal portofolio berisiko tidak bergantung pada tingkat keengganan risiko investor. Investor yang menghindari risiko akan memegang sebagian aset bebas risiko dan sebagian portofolio G; investor yang toleran terhadap risiko akan meminjam pada $R_F$ untuk berinvestasi lebih dari 100% pada portofolio G. Tetapi semua investor memegang proporsi relatif aset berisiko yang sama dalam portofolio G.

Key Insight

Separation theorem menyatakan bahwa portofolio berisiko optimal adalah sama untuk semua investor, tanpa memandang toleransi risiko mereka. Portofolio titik singgung G memaksimalkan Sharpe ratio dan merupakan satu-satunya portofolio berisiko yang akan dikombinasikan semua investor dengan aset bebas risiko.

5.3 Lending dan Borrowing pada Tingkat yang Berbeda

Ketika tingkat lending (biasanya lebih rendah) berbeda dari tingkat borrowing (biasanya lebih tinggi), efficient frontier menjadi patah (kinked). Investor dapat meminjamkan pada $R_F$ (tingkat lebih rendah) tetapi harus meminjam pada $R_F'$ (tingkat lebih tinggi). Efficient frontier terdiri dari tiga segmen: (1) dari $R_F$ ke titik singgung G (segmen lending), (2) sepanjang efficient frontier berisiko dari G ke H, dan (3) dari H sepanjang sinar dari $R_F'$ (segmen borrowing). Ini menciptakan rentang kecil portofolio berisiko (G ke H) yang dapat menjadi optimal bagi investor yang berbeda, tergantung pada toleransi risiko mereka. Jika kedua tingkat tersebut berdekatan, asumsi tingkat tunggal memberikan aproksimasi yang wajar.

  • Kombinasi aset bebas risiko dan portofolio berisiko terletak pada garis lurus.
  • Portofolio titik singgung G memaksimalkan Sharpe ratio.
  • Separation theorem: semua investor memegang portofolio berisiko G yang sama, hanya berbeda dalam campuran dengan aset bebas risiko.
  • Ketika tingkat lending dan borrowing berbeda, efficient frontier memiliki patahan, dan rentang portofolio berisiko dapat menjadi optimal.

6. Pertimbangan Praktis dalam Estimasi Input

6.1 Input yang Disesuaikan dengan Inflasi

Untuk cakrawala investasi jangka panjang (misalnya, dana pensiun), investor peduli pada daya beli riil portofolio mereka, bukan hanya return nominal. Menerapkan kerangka efficient frontier pada return yang disesuaikan dengan inflasi adalah salah satu pendekatan. Data historis menunjukkan bahwa Treasury bills berkorelasi dengan inflasi dan berfungsi sebagai lindung nilai inflasi parsial, sementara saham dan obligasi memiliki sensitivitas inflasi yang berbeda. Sekuritas yang terkait inflasi (misalnya, TIPS di AS) menyediakan lindung nilai inflasi yang hampir sempurna dan semakin penting sebagai kelas aset dalam optimasi portofolio.

Example

Data historis (1926–sekarang) tanpa penyesuaian inflasi: saham rata-rata 11.8%, std dev 20.3%; obligasi rata-rata 6.4%, std dev 8.4%; T-bills rata-rata 3.6%, std dev 3.1%. Setelah penyesuaian inflasi: saham rata-rata 8.6%, std dev 20.3%; obligasi rata-rata 3.4%, std dev 9.5%; T-bills rata-rata 0.6%, std dev 3.9%. Korelasi antara T-bills dan inflasi adalah 0.41, menunjukkan lindung nilai parsial.

6.2 Ketidakpastian Estimasi Input

Input yang andal sangat penting untuk optimasi mean–variance. Data historis umumnya digunakan sebagai titik awal, tetapi terdapat trade-off yang penting. Seri waktu yang lebih panjang meningkatkan presisi estimasi rata-rata (standard error rata-rata menurun seiring $\sqrt{N}$), tetapi karakteristik sekuritas berubah seiring waktu, sehingga data yang lebih lama menjadi kurang relevan. Prediksi variance return mencakup baik variance yang melekat maupun ketidakpastian dari tidak diketahuinya rata-rata sebenarnya: $\sigma^2_{Pred} = \sigma^2 + \sigma^2 / T$, di mana $T$ adalah jumlah periode waktu. Dengan demikian prediksi variance selalu lebih besar daripada variance historis.

Ketika kelas aset baru dengan sejarah terbatas ditambahkan, analis harus memilih antara menggunakan semua data yang tersedia (seri yang lebih panjang untuk aset yang mapan, lebih pendek untuk aset baru) atau hanya menggunakan periode yang sama. Pilihan ini secara signifikan memengaruhi estimasi input dan portofolio optimal yang dihasilkan.

Key Insight

Ketidakpastian input berarti bahwa prediksi variance return selalu lebih besar daripada variance historis. Ukuran sampel yang terbatas menimbulkan estimation risk, yang sangat parah untuk expected return (yang memiliki standard error besar) dan untuk korelasi ketika seri waktu pendek.

6.3 Cakrawala Waktu dan Variance

Untuk aset dengan return yang tidak berkorelasi antar waktu, variance dari return kumulatif berskala linear dengan cakrawala. Namun, beberapa aset (misalnya, Treasury bills) menunjukkan autokorelasi positif, yang berarti standard deviation tahunan meningkat seiring cakrawala. Untuk T-bills, standard deviation tahunan selama cakrawala 10 tahun sekitar 6%, dibandingkan dengan 3.2% pada cakrawala 1 tahun. Ini membuat T-bills secara efektif lebih berisiko dalam cakrawala panjang, yang memiliki implikasi untuk alokasi portofolio jangka panjang.

  • Return yang disesuaikan dengan inflasi relevan bagi investor jangka panjang.
  • Ketidakpastian estimasi input meningkatkan prediksi variance melampaui variance historis.
  • Seri waktu yang lebih panjang meningkatkan presisi tetapi dapat mencakup data yang usang.
  • Autokorelasi dalam return memengaruhi bagaimana risiko berskala dengan cakrawala investasi.

7. Contoh Perhitungan

7.1 Alokasi Ekuitas dan Utang

Pertimbangkan alokasi antara saham (S&P 500) dan obligasi. Estimasi input: $\bar{R}_S = 11.8\%$, $\sigma_S = 20.3\%$, $\bar{R}_B = 6.4\%$, $\sigma_B = 8.4\%$, $\rho_{SB} = 0.01$. Bobot portofolio variance minimum untuk saham adalah $X_S^* = (\sigma_B^2 - \sigma_S \sigma_B \rho_{SB}) / (\sigma_S^2 + \sigma_B^2 - 2 \sigma_S \sigma_B \rho_{SB}) = (70.56 - 0.01 \cdot 20.3 \cdot 8.4) / (412.09 + 70.56 - 2 \cdot 0.01 \cdot 20.3 \cdot 8.4) = 0.144$. Jadi portofolio variance minimum adalah 14.4% saham, 85.6% obligasi, dengan $\sigma_P = 7.8\%$.

Dengan tingkat bebas risiko 1%, portofolio titik singgung T memiliki $\bar{R}_T = 7.75\%$ dan $\sigma_T = 8.13\%$, menghasilkan Sharpe ratio sebesar $(7.75 - 1)/8.13 = 0.83$. Komposisi T adalah 25% saham dan 75% obligasi. Efficient frontier dengan riskless lending and borrowing adalah $\bar{R}_P = 1 + 0.83 \sigma_P$.

7.2 Alokasi Saham Domestik dan Internasional

Pertimbangkan indeks saham domestik ($\bar{R}_S = 11.8\%$, $\sigma_S = 20.3\%$) dan portofolio saham internasional ($\bar{R}_{int} = 9.2\%$, $\sigma_{int} = 18.4\%$, $\rho_{S,int} = 0.66$). Bobot portofolio variance minimum untuk saham domestik adalah $X_S^* = (18.4^2 - 0.66 \cdot 20.3 \cdot 18.4) / (20.3^2 + 18.4^2 - 2 \cdot 0.66 \cdot 20.3 \cdot 18.4) = 0.36$. Jadi 36% domestik, 64% internasional, dengan $\sigma_P = 17.5\%$—lebih rendah dari kedua standard deviation individual, yang menunjukkan manfaat diversifikasi.

Portofolio internasional saja (risiko 18.4%, return 9.2%) tidak efisien: seorang investor yang menerima risiko 18.4% dapat mencapai return 10.2% dengan menggunakan 37% domestik dan 63% internasional—peningkatan return sebesar 1% tanpa risiko tambahan. Dengan tingkat bebas risiko 1%, portofolio titik singgung adalah 70% domestik, 30% internasional, dengan $\bar{R}_T = 11\%$, $\sigma_T = 18.3\%$, dan Sharpe ratio sebesar 0.552.

7.3 Alokasi Tiga Aset

Menggabungkan obligasi, saham AS, dan saham internasional (dengan $\rho_{B,int} = 0.05$), portofolio titik singgung pada tingkat bebas risiko 1% memiliki proporsi: 73% obligasi, 21% saham AS, 6% saham internasional. Expected return-nya adalah 9.5%, standard deviation 10.5%, dan Sharpe ratio 0.905. Efficient frontier tiga aset ini mendominasi frontier dua aset (saham–obligasi dan saham–internasional) karena menawarkan Sharpe ratio yang lebih tinggi (0.905 vs. 0.83 vs. 0.552).

Key Insight

Menambahkan lebih banyak kelas aset ke efficient frontier hanya dapat meningkatkan (atau membiarkan tidak berubah) Sharpe ratio maksimum yang dapat dicapai. Frontier tiga aset mendominasi frontier dua aset, yang menggambarkan manfaat diversifikasi yang lebih luas.

  • Rumus bobot portofolio variance minimum digunakan untuk menemukan alokasi berisiko terendah.
  • Portofolio titik singgung memaksimalkan Sharpe ratio dan merupakan portofolio berisiko optimal berdasarkan separation theorem.
  • Memperluas himpunan aset meningkatkan efficient frontier.

8. Kewaspadaan Praktis

Beberapa peringatan penting berlaku untuk penggunaan praktis kerangka efficient frontier:

  • Input estimation risk: Efficient frontier hanya sebaik inputnya. Expected return, variance, dan korelasi diestimasi dengan kesalahan, dan portofolio optimal dapat sangat sensitif terhadap estimasi ini. Perubahan kecil pada input dapat menghasilkan perubahan besar pada alokasi optimal.
  • Mengaitkan asosiasi dengan kausalitas: Memperoleh posisi pada efficient frontier tidak menetapkan kausalitas antara bobot aset dan hasil. Frontier adalah alat deskriptif berdasarkan input yang diasumsikan, bukan model kausal.
  • Mengabaikan asumsi model: Kerangka mean–variance mengasumsikan bahwa investor hanya peduli pada rata-rata dan variance (atau bahwa return terdistribusi normal). Jika return memiliki skewness, kurtosis, atau fitur lain, efficient frontier mungkin tidak menangkap seluruh himpunan risiko yang relevan.
  • Menginterpretasikan intercept secara keliru: Tingkat bebas risiko $R_F$ diasumsikan konstan dan diketahui. Dalam praktiknya, tingkat bebas risiko berubah seiring waktu, dan meminjam pada tingkat bebas risiko mungkin tidak tersedia bagi semua investor.
  • Satuan pengukuran: Semua input harus dinyatakan dalam satuan yang konsisten (misalnya, return dan standard deviation tahunan). Mencampur angka bulanan dan tahunan menghasilkan hasil yang tidak benar.
  • Mengacaukan kesalahan dan residual: Dalam konteks analisis portofolio, istilah "kesalahan" dan "residual" memiliki makna spesifik. Residual adalah selisih antara return aktual dan return prediksi; kesalahan adalah selisih antara return aktual dan return yang diharapkan. Keduanya tidak dapat dipertukarkan.
  • Masalah variabel yang dihilangkan: Analisis efficient frontier hanya mempertimbangkan aset yang dimasukkan dalam optimasi. Jika kelas aset penting dihilangkan, frontier yang dihasilkan mungkin suboptimal dibandingkan dengan himpunan yang lebih lengkap.
  • Parameter yang berubah seiring waktu: Korelasi dan variance berubah seiring waktu. Menggunakan rata-rata historis tanpa menyesuaikan dengan kondisi saat ini dapat menghasilkan alokasi yang usang.

Key Insight

Efficient frontier adalah alat teoretis yang kuat, tetapi penerapan praktisnya memerlukan perhatian cermat pada estimasi input, asumsi model, dan perbedaan antara perhitungan dan interpretasi. Memperoleh koefisien atau bobot portofolio tidak secara otomatis menetapkan bahwa alokasi tersebut optimal dalam kondisi dunia nyata.

  • Input estimation risk adalah keterbatasan praktis paling signifikan dari optimasi mean–variance.
  • Efficient frontier sensitif terhadap perubahan kecil pada expected return.
  • Asumsi model (normalitas, korelasi konstan, tingkat bebas risiko diketahui) sering dilanggar dalam praktik.
  • Manfaat diversifikasi nyata tetapi bergantung pada estimasi korelasi yang akurat.
  • Selalu validasi frontier dengan pengujian di luar sampel dan analisis sensitivitas.
